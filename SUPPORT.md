# Getting help

For Bresca services, project enquiries or product support, visit [bresca.ai](https://bresca.ai/en/contact) or email [hello@bresca.ai](mailto:hello@bresca.ai).

For a reproducible code issue in a public repository, open an issue there and include the affected version, expected behavior and reproduction steps. Follow repository-specific guidance when available. Keep account details and customer data out of public issues.
