# Bresca GitHub profile

Public organization profile and shared community guidance for [Bresca](https://bresca.ai).

- `profile/README.md`: the public organization overview.
- `assets/`: existing Bresca brand marks, copied without modification from the company website.
- `SUPPORT.md`, `SECURITY.md`, `CONTRIBUTING.md`: fallback guidance for repositories without their own files.

Edit Markdown directly and preview it on GitHub. Check links and both logo variants before publishing. Only list client work already published in the Bresca portfolio. Keep private repository details in `.github-private`.

No build or GitHub Actions workflow is needed. Brand assets remain Bresca property; this repository does not grant a new trademark or software license.
